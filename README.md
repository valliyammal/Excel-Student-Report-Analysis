# Excel Student Report Analysis

## Project Overview
This project analyzes student academic performance using Microsoft Excel. It helps identify score patterns and compare performance across student groups.

## Dataset
- Total Students: 1,000
- Student demographics and background
- Math, Reading, and Writing Scores
- Test Preparation Course Details

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Interactive Slicers
- KPI Cards

## Key Performance Indicators (KPIs)
- Total Students: 1,000
- Highest Score: 100
- Lowest Score: 9
- Overall Average Score: 67.77

## Dashboard Features
- Average Score by Gender
- Average Score by Student Group
- Average Score by Test Preparation Course
- Interactive Slicers for filtering data
- KPI Cards for performance summaries

## Key Insights
- Female students have a higher average score than male students in this dataset.
- Group E has the highest average score among the student groups shown.
- Students who completed the test preparation course have a higher average score than those who did not.
